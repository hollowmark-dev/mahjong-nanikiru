# 何切る道場

制限時間つきの**立体何切る**練習アプリです（リーチ麻雀・赤ドラ3枚）。
卓の4人の捨て牌とドラ表示牌を見て、手牌から1枚切ります。全候補をシミュレーションで評価し、
最善手との差と回答の速さで採点します。「今日の10問」は全員が同じ問題を解くので、友達どうしでランキングを競えます。

**遊ぶ:** https://hollowmark-dev.github.io/mahjong-nanikiru/

## 採点

```
q        = 選んだ牌の和了率 / 最善手の和了率
基礎点   = 100 × max(0, 1 − 3 × (1 − q))   … q=0.9で70点、0.8で40点、2/3以下は0点
時間係数 = 1 + 0.5 × (残り時間 / 制限時間)
得点     = 基礎点 × 時間係数（1問最大150点、10問で最大1500点）
```

- 正確さに時間係数を掛けるので、適当に早押ししても点は伸びません。
  本番の問題で試算すると、ツモ牌を即タップし続けた場合は約550点、6割最善・4割次点を10秒で答えた場合は約1060点です。
- 時間切れは0点です。
- 赤5を切ったとき、同じ種類の通常の5が手にあれば q を0.9倍にします。
- 「ツモ切りが正解」の問題は全体の15%までに抑えています。
- 押し引きの問題（今日の10問の4・7・10問目）は、期待収支（点）の損失で採点します。
  `基礎点 = 100 × max(0, 1 − 損失 / 3000)`（損失 = 最善の期待収支 − 選んだ牌の期待収支）。3000点以上損すると0点です。
  時間係数・時間切れ・赤5の扱いは同じで、赤5を切ると損失に300点を足します。ランクは損失 0で最善、300以下で好手、900以下で次善、それ以外は悪手です。

## 評価の仕組み

候補ごとに、切った後の手を1万回シミュレーションして和了率を出します。

- 山は、136枚から「自分の手・ドラ表示牌・全員の河」を除いた牌です（見えている牌は山にない）。
- 1巡ごとに自分がツモり、他家3人も1枚ずつ切ります。他家の打牌が待ちに当たればロンします（フリテンならロンできません）。
- 他家の和了による局の打ち切りと、ロンできる打牌の割合を入れて、実戦の和了率に近づけています。
- シミュレーション内の自分の打ち方は「シャンテン数を下げる → 受け入れ最大 → テンパイ後は待ちの多いほうへ待ち替え」です。

速度問題では、役・打点は評価に含みません。

### 押し引き

他家1人がリーチしている局面で、候補ごとに「押す／降りる」を含めた続きを1万回シミュレーションし、
**期待収支（点）**で比べます。東1局0本場・自分が親・全員25000点の素点の期待値です。

- リーチ者の手は、見えている情報（河・宣言後に通った牌・見えている枚数）と矛盾しないテンパイ形を毎回ランダムに作ります。
  実際の手は使わないので、正解が結果論になりません。危険度は実戦の統計の水準（無スジ4〜6で約13%、スジの1・9で約3.5%）に較正しています。
- 和了点は役・符・ドラ・赤・裏ドラから計算します（`docs/js/engine/score.js`）。
- 簡略化している点:
  - 自分はテンパイしたら必ず即リーチします。1シャンテンでは安全な牌があれば押し、なければ降ります。一度降りたら押し返しません。
  - リーチ者以外の他家は、山の牌を無作為に切ります（リーチ者の当たり牌は3割の確率でしか切りません）。他家の鳴き・リーチ・和了は「局の打ち切り」としてまとめて扱います。
  - 降りるときの安全度は事前の推定と、その後に通った牌だけで決めます。
  - 扱う役は門前の主な役だけです（一発・海底・嶺上・二盃口・小三元・混老頭などは扱いません）。役満は国士無双と四暗刻だけで、数え役満はありません。
  - 順位・ウマ・テンパイ料・本場は扱いません。

## 開発

依存パッケージはありません（Node 24 で動作確認）。

```bash
npm test
```

```bash
npm run serve
```

```bash
node scripts/generate.mjs --count 1500 --trials 10000 --seed 12345 --out docs/data/problems.json
```

- `docs/` がそのまま GitHub Pages で配信されます（ビルド手順なし）。
- 問題は `scripts/generate.mjs` で事前に生成し、評価値と一緒に `docs/data/problems.json` に入れています。
- 仕様の正本は [SPEC.md](SPEC.md) です。
- ランキングは Google Apps Script で動いています。設定方法は [gas/README.md](gas/README.md) を見てください。

牌の画像はすべてコードで描いた自作のSVGです。
