# ランキング用 GAS のデプロイ手順

ランキングは Google スプレッドシート＋Google Apps Script（GAS）で動きます。サーバー代はかかりません。

## 1. スプレッドシートを作る

1. Google ドライブで新しいスプレッドシートを作る（名前は何でも可、例「何切る道場ランキング」）。
2. シート名やヘッダ行は自動で作られるので、中身は空のままでよい。

## 2. スクリプトを貼り付ける

1. メニューの「拡張機能」→「Apps Script」を開く。
2. 最初からある `コード.gs` の中身を全部消し、このリポジトリの `gas/Code.gs` の内容をそのまま貼り付ける。
3. 保存（Ctrl+S）。
4. （任意）上のプルダウンで関数 `selfTest` を選んで「実行」。「selfTest OK」と出れば計算ロジックは正常。
   初回は次の「承認」の画面が出る。

## 3. ウェブアプリとしてデプロイする

1. 右上「デプロイ」→「新しいデプロイ」。
2. 歯車アイコン→「ウェブアプリ」を選ぶ。
3. 設定:
   - 説明: 何でも可（例 v1）
   - **次のユーザーとして実行: 自分**
   - **アクセスできるユーザー: 全員**
4. 「デプロイ」を押す。

### 「このアプリは Google で確認されていません」と出たら

自分で書いたスクリプトを自分のアカウントで動かすだけなので、次の順で進めて問題ありません。

1. 「アクセスを承認」→ Google アカウントを選ぶ。
2. 「このアプリは Google で確認されていません」の画面で左下の「詳細」を押す。
3. 「（プロジェクト名）（安全ではないページ）に移動」を押す。
4. 「許可」を押す（スプレッドシートの読み書きと外部サービスへの接続の権限）。

デプロイが終わると「ウェブアプリ」の URL（`https://script.google.com/macros/s/.../exec`）が表示されるのでコピーする。

## 4. アプリに URL を設定する

`docs/js/config.js` を開き、コピーした URL を入れてコミット・公開する。

```js
export const RANKING_ENDPOINT = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

空文字のままならランキング機能は隠れます。

## 5. 動作確認

ブラウザで `<URL>?action=daily&date=2026-10-03` を開き、`{"ok":true,"rows":[]}` のような JSON が出れば成功。
アプリで「今日の10問」を最後まで解くと、スプレッドシートの `scores` シートに1行増えます。

## コードを更新したとき

URL を変えずに更新できます。

1. Apps Script でコードを貼り替えて保存。
2. 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン（編集）。
3. バージョンを「新バージョン」にして「デプロイ」。

「新しいデプロイ」を選ぶと URL が変わってしまうので、必ず「デプロイを管理」から編集してください。
（保存しただけでは公開中のウェブアプリには反映されません。）

## 補足

- `scores` シートはスクリプトが自動で作ります(全列を「書式なしテキスト」にして、数式や型の自動変換を防ぎます)。
  すでに `scores` シートを自分で作っている場合は、全列(A〜H)を選び、メニューの「表示形式」→「数字」→「書式なしテキスト」にしてください。名前の先頭の `= + - @` はスクリプト側でも除去します。
- 同じ端末・同じ日の2回目の送信は無視されます（最初の1件だけ有効）。やり直したい場合は `scores` シートの該当行を削除。
- 受け付けるのは日本時間の「今日」と「昨日」の日付だけです。
- 友達どうしで遊ぶ前提のため、スコアの再計算などの不正対策はしていません。
